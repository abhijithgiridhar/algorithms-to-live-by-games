Linear search

Check every box, in order, until you find it or run out. Worst case: checks.

for i in range(len(list)):
    if list[i] == target:
        return i
return "not found"

Binary search

Because the list is sorted, check the middle box, then throw away the half that can't contain the target. Worst case: checks.

lo, hi = 0, len(list) - 1
while lo <= hi:
    mid = (lo + hi) // 2
    if list[mid] == target:
        return mid
    elif list[mid] < target:
        lo = mid + 1
    else:
        hi = mid - 1
return "not found"

The idea: a sorted list is a resource. Every time you check the middle of what's left, you cut the remaining possibilities in half — that's why binary search needs so few checks even on a huge list. A linear search ignores that structure and pays for it.
