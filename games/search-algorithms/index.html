What you just did

🐢 The slow way: check one by one

Worst case: checks on this list.

  1. Start at the first box.
  2. Is this the number? If yes, done!
  3. If not, move to the next box and ask again.
  4. Keep going until you find it — or run out of boxes.

🐇 The smart way: split in half each time

Worst case: checks on this list.

  1. Because the list is sorted, check the box in the exact middle.
  2. Too big? The number must be to the left — forget the whole right half.
  3. Too small? Forget the whole left half instead.
  4. You've now got half as many boxes to search. Repeat the same trick on what's left.

The idea: a sorted list is a shortcut waiting to be used. Every time you check the middle of what's left, you throw away half the remaining boxes at once — that's why the smart way barely grows even on a huge list, while checking one by one gets slower and slower.
