Variant 4: Availability depends on others

This is the classic problem with one big change: the spots aren't just yours to accept or reject. Every other driver on the road wants one too, so how many are actually free depends on the crowd, not chance alone.

The key number is the occupancy rate — the share of spots already taken. The busier it is, the sooner you should grab a spot, well before you feel like you "should" have to.

  1. Estimate the occupancy rate.
  2. Look up the distance from the destination where you should start taking any free spot.
  3. Drive past free spots until you're within that distance.
  4. Then take the very first free spot you see.

The formula: distance ≈ 0.69 ÷ (share of spots that are free). At 90% full, that's 0.69 ÷ 0.10 ≈ 7.

Now in code

def park(spots_from_destination, start_taking_within):
    for distance in reversed(spots_from_destination):
        is_free = check_spot(distance)
        if distance <= start_taking_within and is_free:
            return distance   # park here
    return "overflow lot"     # never found one in range
