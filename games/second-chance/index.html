    Variant 1: Second chances allowed

    In the classic problem, passing on an offer loses it forever. Here, you get a safety net: if nothing else works out, you can go back to your favorite — but there's a real chance it's gone by then.

    A safety net means you can afford to be a little greedier. It's worth looking a bit longer than the classic 37% rule allows, because if it doesn't pay off, you might still recover your favorite. The less likely that recovery is to work, the closer the right strategy gets back to the classic rule.

    1. Look at the first 61% of startups without accepting anyone. Remember the best one.
    2. Leap: after that, accept the first startup better than everything you've seen.
    3. If you reach the end with nobody accepted, email the best one from your look phase back — and hope it's still open.

    def find_internship(startups, look_phase=6):
    best_score_seen = 0
    best_so_far = None

    for i, startup in enumerate(startups):
        if i < look_phase:
            if startup.score > best_score_seen:
                best_score_seen = startup.score
                best_so_far = startup
            continue

        if startup.score > best_score_seen:
            return startup            # accept!

    # reached the end -- go back and hope it's still open
    if random() < 0.5:
        return best_so_far            # still open!
    return None                       # gone -- no internship
